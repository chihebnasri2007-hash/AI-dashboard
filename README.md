# AI-Dashboard

A local AI-powered dashboard for analyzing CSV and Excel data using Python, Streamlit, and Google Gemini.

## Features

- Upload CSV or Excel files
- Interact with your data using AI-powered insights
- Built with Python and Streamlit

## Setup Instructions

1. Clone this repository:

```bash
git clone https://github.com/chihebnasri2007-hash/AI-dashboard.git
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the app:

```bash
streamlit run app.py
```
