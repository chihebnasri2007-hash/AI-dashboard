# AI-Dashboard
A local AI-powered dashboard for analyzing CSV and Excel data using Python, Streamlit, and Google Gemini.

## Features
- Upload CSV or Excel files.
- Interact with your data using AI-powered insights.
- Built with Python and Streamlit.

## Setup Instructions
1. Clone this repository:
   ```bash
   git clone [https://github.com/chihebnasri2007-hash/AI-dashboard.git](https://github.com/chihebnasri2007-hash/AI-dashboard.git)


   #Install the required dependencies:
   pip install -r requirements.txt

   #Run the application:
   streamlit run app.py


   ### A Quick Tip
If you haven't created a `requirements.txt` file yet, I highly recommend doing so. This file lists all the Python libraries (like `streamlit`, `pandas`, `google-generativeai`, etc.) that someone else needs to install to run your code. You can create this by running `pip freeze > requirements.txt` in your terminal.
